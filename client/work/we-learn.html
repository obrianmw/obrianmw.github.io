How it's built

Small, readable, ready to grow

The app is a Flask project with Jinja templates and a separate stylesheet served from its static folder. The landing page invites visitors to "Share The Little You Know", the starting point for a community where learners teach each other.

Keeping the structure plain means new pages and features slot in without rework, which suits a project I build on alongside work and study.
