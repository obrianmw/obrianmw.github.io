The idea

Learning is better shared

Everyone starts out confused about something. Confused Learner is a place to work things out together: I post what I'm learning, and the people the page reaches learn alongside me.

It's a two-way page. Anybody is welcome to add their input: ask a question, answer one, correct a mistake or share something you know. Every comment makes the page more useful for the next person who finds it.

A web home in the making

Alongside the page I'm building a companion website in Python and Flask with the same message, "Learn Every Day" and "Share The Little You Know", so lessons and contributions can live in one place beyond the news feed.
